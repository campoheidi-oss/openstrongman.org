# Data Contributors

OpenStrongman itself stays unattributed — no maintainer names on the site or in the repo's public identity. That policy is about the project's own branding, not about the people who send in data.

Anyone who submits meet data, corrections, or verification work can opt in to be listed here with their real name and ORCID iD. Being listed is **opt-in only** — submitting data does not add you to this file automatically; you have to ask to be added, or say so in your pull request.

Once a contributor is listed here with an ORCID iD, that same iD gets included in the Zenodo deposit metadata for the next data release (see `ZENODO-SETUP.md`). If the contributor has ORCID auto-update enabled, the dataset then shows up as a citable work on their own ORCID profile — not just a line in a repo file.

## Role key (CRediT taxonomy)

Use the standard [CRediT](https://credit.niso.org/) contributor role terms so the credit is specific, not just "helped out":

| Role | Meaning here |
|---|---|
| Data curation | Compiled, cleaned, or structured results for a meet or federation |
| Validation | Verified results against official sources, scoresheets, or livestream footage |
| Resources | Provided source material (photos, PDFs, livestream links, scoresheets) |
| Writing – review & editing | Corrected schema, categorization, or documentation errors |

A contributor can hold more than one role.

## How to be listed

Open a pull request adding a row to the table above, or say so in the PR/issue that adds your data, and include:

- Your name as you want it to appear
- Your ORCID iD (get one free at [orcid.org/register](https://orcid.org/register) if you don't have one)
- Which role(s) from the table above apply
- Which meet(s) or dataset(s) you contributed to

If you'd rather stay uncredited, don't add yourself — nothing about contributing requires being listed.
