# OpenStrongman Data

Each CSV in this folder holds one competition stage, one row per athlete per event. Files are listed in `../manifest.json`, which is what the site loads.

- **Data rules** (columns, event types, edge cases, current spellings): [DATA-RULES.md](DATA-RULES.md)
- **How to contribute** (process, GitHub steps, review): [../CONTRIBUTING.md](../CONTRIBUTING.md)
